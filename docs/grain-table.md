# Grain table

Document type → unit of independent meaning.

| Document type | Unit | Notes |
|---|---|---|
| Articles of Association | Article | Definitions (article 1) in one file |
| Management lease | Clause, and schedule, each taken whole | Short clauses whose sub-clauses read as one provision; the definitions clause in one file; execution page and plans left out |
| Individual lease | Sub-clause; schedule paragraph | Words of a clause outside its sub-clauses in one concept; a part with a single unnumbered paragraph is one concept; the definitions table and the particulars table each in one file |
| RICS Service Charge Code | Section (n.n) | Sub-sections (n.n.n) stay inside their section; appendix B entries are one each; appendices A, C and D are one each; the glossary table is one file; front matter is skipped |
| Title register | Register (A: Property, B: Proprietorship, C: Charges) | Entries as a markdown table; the schedule of notices of leases as a second table; the register summary and page-1 disclaimer left out |
| Agency agreement | Sub-clause | A clause with no sub-clauses is one concept, and a clause's opening words before its sub-clauses are their own; each appendix is one concept; the definitions clause is one file; the signature block and audit trail are left out |
