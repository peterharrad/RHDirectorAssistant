# sources/

Source documents, with file names matching the `source` entries in
`config/manifest.yml`.

This is the public repo, so the real documents are not here: several hold personal data
or are confidential or copyright (see [NOTICE.md](../NOTICE.md)). Instead, this folder
holds redacted versions, with the structure, numbering, headings, defined terms and
cross-references kept and the body text replaced with lorem ipsum. They are not the real
documents. The management lease is a scanned document: its redacted text is in
`transcripts/management-lease.md`, and its PDF here is a stand-in for that text.

The exception is the Articles of Association, which are on the public Companies House
register and are included as they are.
